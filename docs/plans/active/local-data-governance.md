# 本地数据治理与升级验收

本地数据治理于 2026-11-21 完成，覆盖 Koma 的本地数据所有权、旧存储迁移、备份恢复及现有 WebDAV 接续。华为云同步待 AGC 表建好后另行启动。

| 搜索历史 | RDB。保留原条数、顺序及搜索范围语义。搜索界面的小型偏好仍由 Preferences 持有。 |
| 章节列表设置、按作品阅读模式和横幅规则、按来源布局与筛选、简介展开 | RDB 按作品或来源键管理。沿原备份范围区分可迁移配置及本机显示状态。 |
| 订阅、源或插件登记和持久设置 | RDB 持有用户管理的记录和可备份的按源观察。索引响应及派生投影由缓存负责。安装包、规则资源和插件代码由文件系统持有。 |
| 追踪绑定及待发送队列、下载队列和书架更新记录 | RDB 按绑定、任务或作品管理，保留原有去重和恢复规则。正文及章节资产、与正文同目录的章清单由文件系统管理。 |
| 应用外观、语言、无痕和自动化开关、当前筛选、少量设备偏好 | Preferences 保存独立小值。按书阅读覆盖和须与它联合提交的阅读器设置由阅读事务持有。 |
| 正文、封面、可重建缓存、备份包、跨进程交接文件及恢复快照 | 文件系统。持久业务主数据从对应 owner 读写，交接与恢复文件使用现有版本化协议。 |
| 认证信息与本机授权 | 由原安全存储和授权 owner 管理。检查应用备份、日志和 WebDAV 负载的既有白名单边界。 |
| WebDAV 远端对象及本机恢复协议 | 保留现有远端格式、版本、范围和操作语义。读取及应用业务数据通过对应 owner。 |

项目的持久化和备份约束见[执行规则](../../agent-guides/koma-rules.md#书库自动化下载与备份)。

## 迁移与恢复验收

1. 记录旧版签名包、方向、数据库版本和各数据域的有效存储。用稳定标识逐条对照，包含空集合、显式清除、缺省字段、顺序、时间戳、私密分类和挂起任务。保留离线证据于本机验证目录。
2. 一次事务内提交每域迁移及完成标记。故障样本覆盖有数据迁移失败后重试、空数据迁移、再次启动、旧数据残留和新版主动清空。恢复时先处理历史检查点，验证旧版写出的待恢复状态，并验证新版回滚后读回。
3. 复用生产导出和恢复入口核对老备份、现行备份、Mihon 和后台备份模板。缺省字段与显式清除分别验证。观察恢复后立即返回原页面的状态及重启后的持久值。
4. 对热路径检查单书、单章或单任务变更的实际读写范围。需要量化首屏或分类切换耗时时，使用同设备、同数据、同界面状态对测。

## 验收记录

三台设备均使用签名的 1.5.6（25）开发候选包覆盖安装。197 和 103 使用 SHA-256 `bd503ffcbcc298461ceac8d5a1b22c57f6584fb353bbd9220fe3dccba2d5a2ca`，201 使用 SHA-256 `eeb2cb642d822c4d1ed079745bd47c2a3a29b0ff5714502608b47e15e20c71c7`。这些包同时含页面边缘回弹的开发改动，此处记录数据治理路径的验收结果。

- 197 的升级后书架逐条一致，包含 1,123 部作品、47,434 章、23 个手动分类和 1,075 条归属。使用前的阅读表全量对照一致。372 条下载任务的顺序和内容、19 条按书阅读模式及现有按书章节设置一致。实际从「国漫」切到「日漫」并切回，搜索页读到 19 条旧记录，漫画续读画面为第 31／136 页。
- 103 的 69 部作品和 5,087 章逐条一致。WebDAV 保留启用、自动同步、连接身份、凭据引用及四个原有数据范围。升级后收到原同步空间的新阅读记录，实际续读画面为第 19／28 页。退出阅读后在本机生成的阅读变更已同步，阅读待发送队列归零。期间出现的一次远端版本变化由后续成功同步恢复。设置页读到新的「上次同步成功」且无待恢复记录。
- 两台设备的已安装源包登记、按源设置及学习到的公开选项逐条核对。图片插件安装内容及文件摘要一致。订阅中更新检查时间或最近错误允许随应用自身检查正常变化。设备数据库均通过 SQLite 完整性检查。
- 本地用真实 SQLite 故障注入验证事务回滚、重试和清除后重启。备份设置验证覆盖旧版检查点、便携字段读回、RDB 订阅失败回滚及后台模板。Mihon 使用 197 的只读数据副本，生产导入准备函数读写暂存快照，保留 1,123 部作品、2,267 条导入关联及原阅读会话。备份覆盖恢复和 Mihon 准备在本地副本验证。本轮未做真机覆盖恢复，也未做升级前后计时对测。
- 201 从 schema 2 直接覆盖升到 schema 4。升级前只有书架迁移标记。首次启动使用已有的调试开关抑制部分自动任务，以便核对原始数据。首个书架页面载入后即读到全部 24 个标记，保留原来 71 部作品、9,122 章和 27 条分类归属。247 条阅读进度、3,256 条章节状态、640 条阅读会话、14 条按书阅读模式、27 条下载任务及 117 个书源登记逐条对照一致。空的横幅覆盖和搜索历史也有完成标记。正常冷启动后标记集合和上述数据保持一致，历史页能读到旧记录，已安装图片规则与原资产摘要吻合。追踪重试计数和书架检查任务状态随自动任务继续更新。
- 201 的升级前日志在 05:19:34 已记录 WebDAV 提交阶段的 `sync_local_busy`。升级后复测，18:48:35 到 18:50:22 期间书架自动检查持有本机写入资格，重叠的 WebDAV 轮次被原有的互斥保护暂缓。普通冷启动后只停留在书架，约 131 秒后于 18:50:44 自动重试成功，前次待提交记录结清，错误清空。WebDAV 的原连接和同步范围通过读回核对，设备已恢复原亮屏设置及休眠状态。
