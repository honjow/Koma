# Koma 跨设备同步设计

设置结构、可见行为和数据方案已通过独立设计评审，并获用户批准实施。开发与验收进度见[当前工作单](../../CURRENT_STATUS.md)。

## 用户能带到另一台设备上的东西

首版提供五组数据。同步在用户连接、核对范围并确认首次合并后才启用。

| 分组 | 同步内容 | 首次连接默认 |
| --- | --- | --- |
| 书架与分类 | 已收藏的可识别公开书源作品、手动分类的名称和顺序、作品所属分类。增删和移动都能传递。 | 选中 |
| 阅读记录 | 可识别公开书源作品的历史、最近阅读章节和页码、逐章阅读位置、已读/未读、章节书签。即使未收藏也能续读。 | 选中 |
| 阅读偏好 | 全局阅读方向和模式、翻页动画、页码显示、图像适配。按书只同步阅读方向和模式，限可识别公开书源作品。 | 不选 |
| 书源订阅 | 共享经过验证的公开目录订阅及名称。设备各自控制实际地址、启停和最近使用顺序。收到的目录可由用户选择加入。 | 不选 |
| 搜索历史 | 实际只查询经确认公开书源的普通搜索词原文。界面仍显示最近 20 条，混合范围、私库、本地和其他限定查询留在本机。 | 不选 |

首版「书架与分类」「阅读记录」均在说明里写明适用于能安全跨设备识别的公开书源作品。无法证实为公开域的账户/私有会话作品暂留本机，首次预览显示跳过数量和原因。书架上现有私库和本地作品及其分类成员关系保留；同步分类删除若仍含本机作品、局部展示策略或智能分类依赖，保留原本机分类 ID、设备成员、视图设置和依赖。断开共享身份，作为本机分类保留，不自动重新上传。收到的取消收藏若关联本机笔记或封面，先显示本机待处理项，用户可确认移出或主动重新收藏。在处理前不会清理本机笔记或图片，也不会把该本机占位当成一次新收藏。内置分类按固定身份识别，只有用户成员关系参与。手动分类名属于用户数据。选中这组会共享手动分类名，即使分类为空或只含本机/私库作品，实际作品和私有成员关系仍留在本机。首次合并前列出分类名并明确提示后续新建、改名也会同步。分类暂时变空不视为删除。

笔记、封面、统计、远程私库和本地文件列入完整方案的后续能力。分别需要并发笔记保全、受校验的资产传输、真实会话的持久唯一身份、服务和账户配对、同一内容的显式配对。实施这些能力前要单独评审范围和界面。本机下载、权限、第三方授权、私有订阅和设备操作偏好有明确保留边界。

## 现有 19 类对照

以下是按当前代码和存储所有者重新归组的 19 项。原始 19 项逐条名单未定位，不能把这张表当作原名单。备份格式有 17 个内容字段，备份页面归并为 7 个标签，三者的分组粒度不同。

| # | 数据与归属 | 现有备份 | 同步决策 |
| --- | --- | --- | --- |
| 1 | 书架作品，LibraryStore / LibraryPersistence | 整份书架记录 | 首版同步有稳定书源身份的收藏和安全展示摘要。本机路径、页面描述和自动刷新结果排除。 |
| 2 | 手动分类与成员，LibraryStore / LibraryPersistence | 分类和成员 | 首版按稳定分类 ID 及独立成员关系同步。旧分类首次登记稳定全局 ID，两个未配对的旧同名分类保留各自 ID 和成员。协议保留原名，目标用固定 ID 顺序试加序号及裁剪长度，按现有本机命名验证跳过内置、智能和本机占用名称，直到得到可落盘名称。预览显示本机将用的名称。共享顺序采用一个有版本的共享分类 ID 序列，已有上移/下移写整次排序动作，不分别写两个 sortOrder。两端并发重排时同一条规则选整个序列，序列外新增共享分类按 ID 补到末尾，并保持原本机分类、智能分类的相对顺序。 |
| 3 | 智能分类与分类视图，LibraryPersistence | 规则及显示策略 | 后续可同步规则，须先处理书源、手动分类及追踪条件依赖。当前选择、过滤和视图状态本机保留。 |
| 4 | 作品笔记，ComicPersonalization | 随作品保存 | 后续同步独立编辑值，支持查看和处理并发的两份笔记。 |
| 5 | 自选封面，ComicPersonalization | 独立图片及引用 | 后续按摘要和引用同步图片，设备本地文件路径不参与。 |
| 6 | 本地书库元数据，LocalLibraryMetadataService | 附加元数据，无本地原件或授权 | 本机保留。只有内容身份配对后才能同步对应元数据，目录、文件和授权独立处理。 |
| 7 | 历史和续读，ReaderSessionStore | 阅读文件 | 首版同步书源作品的最近记录、续读章页与删除标记。 |
| 8 | 逐章位置、已读和书签，ReaderSessionStore | 阅读文件 | 首版按同一章的三个独立事实合并。已读可撤销，书签不改变已读和进度。 |
| 9 | 阅读统计，ReadingStatistics / ReaderSessionStore | 真实会话保存在阅读文件 | 后续仅同步真实会话，先具备唯一事件 ID、重复导入去重、并发会话及统计删除语义。 |
| 10 | 私库服务配置及私库阅读身份，RemoteServerStore | 配置和历史各自备份，凭据排除 | 首版保留本机。后续由用户确认服务、账户及资源映射，同名主机或同名书不自动配对。 |
| 11 | 已安装书源，SourceRuntimeAppRegistry | 普通备份可带包和图标 | 首版记录可解析的源身份和目录线索。安装包和实际启停留本机。后续可同步安装意图，继续经现有确认和校验安装。 |
| 12 | 各书源设置，SourceSettingsStore | 设置块 | 后续只同步确认可移植的字段，源版本与描述符需匹配。登录和访问凭据本机保留。 |
| 13 | 书源设置观测值，SourceSettingObservationStore | 观测块 | 本机保留，属于运行中学到的候选。 |
| 14 | 书源浏览与搜索过滤，SourceFilterPreferencesStore | 筛选块 | 后续按源、场景和设置键独立同步。搜索历史首版作为独立的可选数据。 |
| 15 | 图片插件订阅、安装和设置，ImageRuleStore | 配置快照 | 后续分别评估订阅和用户选择，安装物、执行授权、设备能力和缓存本机保留。 |
| 16 | 阅读器偏好和按书覆盖，ReaderPreferencesStore | 全局及部分按书偏好随设置组 | 首版可选字段级白名单。阅读模式组合包含现有单双页、竖向分页和条漫模式。独立分栏、页面拼接、亮度、模型、手势硬件和性能/网络配置留本机。 |
| 17 | 应用偏好、搜索、书源订阅、追踪策略，各现有所有者 | 覆盖一部分，搜索历史本机、完整订阅和部分偏好缺失 | 首版可选搜索历史及可共享的书源订阅。迁移选源、搜索默认范围等其他持久偏好先补备份契约，再评估是否共享。自动备份、下载、第三方上传策略及本机显示选择保留本机。 |
| 18 | 下载队列与文件，OfflineDownloadQueueStore / OfflineDownloadStore | 可选的队列元数据，无正文和每章下载清单 | 本机保留。历史和书架同步不重建队列、不触发下载。 |
| 19 | 第三方追踪作品映射，TrackerPreferencesStore | 可选映射，凭据和上传队列排除 | 后续只考虑用户已确认且可配对到账户的映射。同步拉取不触发第三方上传。 |

表中 #17 的搜索历史目前归本机，完整订阅在备份中缺失，旧文件只有一个订阅地址。#10 私库访问配置归 RemoteServerStore，私库历史实体实际保存在 ReaderSessionStore。#18 备份仅带队列元数据，无下载文件或每章下载清单。

现有门禁扫描已识别的 ArkData Preferences 所有者和键，并执行备份导出、恢复的宿主测试。它不能证明两个设备的并发合并，也不覆盖所有独立 JSON 文件、AssetStore 和平台权限。部分 owner 在测试中使用替身，扫描动态调用点和已登记缺口都不能证明没有新增遗漏。已知备份缺口另有记录，包含迁移偏好、完整书源订阅、搜索偏好，以及老备份组内缺字段可能删值。同步沿数据所有者增量应用，禁止把备份快照恢复入口接到自动同步。同步新增字段在进入同步适配器时必须标明范围、身份、兼容、重置和隐私边界。现有备份 CI 继续运行。

## 设置结构与用户路径

实查 NextE `ac81c4f5` 和 NextN `e93af48f` 均为「设置 → 存储 → 同步 → WebDAV 同步」。两者在同步总览按数据集开关，WebDAV 子页配置连接和执行。NextE 还在总览放可用的华为云入口。同步组和备份导入导出相邻，Koma 的备份已在独立分类，继续沿用它。

入口为「设置 → 备份 → 同步 → WebDAV 同步」。参考的分组依据是与文件导入导出相邻，Koma 把这两项放在「备份」而非「存储」。保留设置首页现有十个两字分类，将「备份」副标题从「导入与导出」改为「导入、导出与同步」。在现有「备份与恢复」页的创建/恢复操作组之后、备份记录之前放一个独立入口行「同步」，副标题为「在设备间同步书架、阅读记录和偏好」。参考应用的同步组在文件操作之前，这里把现有创建和恢复保留在原页第一组。其余备份动作、分组、标题和行为照旧。备份搜索现在靠固定列表索引定位，插入后要用稳定组标识定位创建、恢复、文件、自动和内容，逐个实测。设置搜索用独立目的键，「同步」到总览，「WebDAV 同步」到连接页。「WebDAV」会看到「备份 · 同步」和「服务 · 私有书库」两个带路径的结果。搜索只导航。普通入口逐级返回并保留滚动位置，搜索入口回到同一搜索和查询，平板继续沿用现有设置导航容器。层级、文案、副标题和搜索落点已获用户确认。

- 总览使用现有原生标题栏、分组列表和返回。顶部「WebDAV 同步」显示未连接、连接待确认、已连接、同步中、待核对或需处理。自动关显示「已连接 · 自动同步已关闭」。未连接可以选内容，作为本机本次连接草稿。已连接的选择属于本机当前连接，不更改另一台设备的开关。无选中组显示「尚未选择同步内容」，没有空同步任务。
- WebDAV 子页按「连接」「运行」「状态」分组。填写地址、账户、口令后点「测试连接」，事前写明会在所选目录建立并清理临时测试对象。探针不含真实数据，标记本机随机 ID，仅清除自己创建的精确路径。中断后本机保留清理记录，重连同一认证端点时重试。无选中范围时仍可主动测试连接，但不会读写真实数据。没有选中组时，成功只显示「连接测试通过」。有选中组时，测试通过进入预览。首次合并成功后自动同步仍关闭，由用户显式开启。
- 首次合并、已关闭组重新启用、切换同步目录和备份恢复后的核对，都显示按组的上传、下载、删除、冲突、跳过以及保留范围。列出将删除或发生冲突的条目，允许逐项选择冲突值并返回修改范围。预览绑定空间 ID、清单强 ETag、当前连接版本、选择、本机所有者修订和完整的影响摘要。确认前任一变化都重算；确认后的条件提交遇到冲突也不得用旧确认提交新影响。旧状态缺行视为未知。无共同基线的同字段有不同值时列出两边，默认暂缓该项且保留两端，用户可选本机、另一端或继续暂缓。与远端单条删除冲突的旧本机值默认保持删除，不作为新操作上传；只有用户选择明确的「重新收藏」「恢复到书签」或「采用本机位置」才发出观察了删除的重建操作。暂缓的事实或依赖它的子操作不改本机、也不改远端，其他无冲突项仍可合并。
- 已连接时有「自动同步」「立即同步」和上次成功时间。自动开关只控制触发，关时可手动。关闭某组后停收停发，保留两边已有数据和此前经授权的待传记录；关闭期间不采集该组的同步操作。重新开启时本机仍存在的变化作为预览候选，缺项按未知，预览明确可能恢复远端仍保存的项目。无选中范围、恢复中、连接或预览无效时禁用同步。配置从真实存储状态初始化，重新进入直接复用上次已加载状态。
- 与两个参考的字段自动保存相比，本候选要求显式验证与启用，保留旧配置直到变更成功。未连接页返回/取消丢弃未保存的口令草稿，进程被杀不会激活待确认连接。已连接可编辑，取消或失败后旧连接仍有效。相同地址、账户和已验证空间只换密码可保留待传记录；地址、账户、目录或空间变了则新建连接，重新预览。切换、断开或暂停立即禁止新的提交。尚未发出的请求可取消，已发出的请求等待本轮有界超时。结果未知仍可完成断开并清除本机凭据，明确显示「上次提交结果未知」，旧空间意图隔离保存，只有重新授权同一空间后才核对。迟到回调不写入新连接状态，本机数据及远端文件保留。
- 已使用目录的清单缺失、同目录空间 ID 改变、清单修订倒退或同修订内容不同，都暂停读写及自动任务，提示核对目录并联系服务器管理员。恢复旧快照需要明确确认另建新同步空间和合并，旧待上传队列不能静默跨空间。全新设备没有已见代次，只能报告当前空间及预览影响。
- 资料拉回后从原书架和历史入口打开。缺源时保留书名、源名和章节/页码，例如「未安装「MangaDex」 · 第 12 话，第 8 页」。显示「查找书源」，去现有订阅内按精确源 ID 查找，候选显示已配置的目录及来源。已配置目录查找区分「没有匹配」「目录暂不可用」「订阅已停用」。没有精确匹配时允许复制源标识或走本地导入，禁止使用近似名或远端链接安装。进入查找记住来源条目和滚动位置。装好或启用后回原书架/历史条目，由用户点续读，取消或失败则原章页照旧。禁用、版本不兼容、目录存在但章失效、临时网络失败分别提示「启用书源」「更新书源」「打开章节列表」「重试」。网络失败和标识不一致都保留原位置，不跳进第 1 页冒充续读。可信摘要只用于展示，不能给未知 URL 自动装包或执行代码。
- 错误由失败步骤映射到处理动作。凭据错误提示修改连接，无写权限提示检查目录权限，条件写入不可靠提示换支持的目录，服务器满提示清空间，本地写入失败保留待同步记录，清单损坏/版本过新保留本机数据并提示恢复服务器文件/升级应用。自动失败聚合成一条可持续查看的状态，手动失败保留当前表单。网络断开后本机照常使用，恢复后重试。

## 记录身份、合并与删除

- 书源作品键是结构化的「来源类型、经确认的包身份、原始作品 ID」，章节再加原始章节 ID。可同步合同按已审查的目录发行身份及支持版本列出稳定 ID 语法、页位能力和无账号访问能力。包自报公开、包名相同、已装目录地址和标题都不能证明作品是公开的。发端要求本机有包版本及具体作品的匿名访问来源证据。Host 验证上下文拒绝授权头、Cookie、私有 RPC、认证重定向和携带凭据的 URL、请求体或设置，不写普通会话或观测缓存。旧记录只从可证来源或在预览中按需验证补齐。接收端离线校验协议字段、发行身份和标识语法，不执行源。合同已知但源未安装时生成不可打开的待解析条目，用户从正常路径安装/查阅时再验证。合同未知的记录隔离并在同空间保持原字节，不能当作本机数据再上传或跨空间迁移。发送和接收使用独立字段表，作品和章键受源专属语法约束，仅显示有界普通文本、源可辨名称和安全元数据。现有 `Comic`、历史 DTO、原始/签名 URL、绝对路径、账户态和网络响应不直接序列化。首版合同验证从源码已核候选开始，包括 MangaDex `org.mangadex.koma` 0.1.25（作品 `mdx:<UUID>`、章节 `ch:<UUID>`）、xkcd（中文）`com.xkcd.zh.koma` 0.1.7（`xkcd:zh`、`xkcdch:zh:<正整数>`，分组版含数字组码）。MangaDex 多页、xkcd 缺源回流分别真机验收。其他源逐个按同一合同加入，并显示当前支持及跳过范围；候选源码版本不表示已通过发行来源和真机验证。
- 续读按作品保存章键和最近一次实际进入该章的选择，页位按章节保存原始逻辑页、当时页数和可验证的稳定页标识。按现有意图区分预载、普通详情、恢复已有位置和实际阅读。读取回填、页面载入、退场时的重复保存不产生新编辑。两端确认同一页表才可用逻辑页序回退。Host 按页序补的 ID 不是源提供的稳定 ID，同章同页数也不足以证明页表一致。保留来源声明及可验证页表指纹，验同页数重排、不同源设置和合成 ID；设备本地分栏不进页位记录。页标识失配、页数变化或章不再可用时保留远端章页，提示打开目录或重新定位。已选章继续从该章当前合并页位读取，真实重读允许向前。
- 每次用户动作得到 `(replicaId, seq)`，同一副本持久单调递增。每个事实寄存器保存候选版本、已观察的每副本序号向量及变更种类。普通操作在动作产生时捕获该事实的向量，导入与回写沿用原版本；会话内迟到的结果只能携带原动作向量。合并按向量偏序移除被因果覆盖的候选，重复同一版本幂等。并发时保留仍在前沿的候选。同键显式删除、取消和未读重置作为独立屏障集合保留，即使有效新值覆盖了旧可见值也不清屏障。正值必须观察该键全部有效屏障才能投影；后继屏障可吸收已观察的旧屏障。批量清除另存每键的已见序号向量，只隐藏被向量覆盖的旧值，不能压过未观察到的同键新事件。同类型候选以协议固定的副本 ID 顺序、同副本序号顺序投影；因果明确时后继版本优先。设备 UTC 仅用于展示，不决定胜负。用户可在本次同步结果查看同一作品并发的两个续读位置，选择另一位置是一次观察了双方的新动作。
- 收藏、分类名称/顺序、成员边、续读选章、逐章页位、已读、书签、各偏好项各有独立版本。标记未读为带同一动作 ID 的原子操作，写已读为否，并对该章写第 1 页重置，当前续读指向该章时随页位显示第 1 页；它不改指向另一章的续读，也保留书签。另一个副本尚未见重置的同章页位更新不能盖过重置。单章书签取消为明确删除，书签与阅读事实并发都生效。批量动作的成员以用户实际选择的章节为准。同一章并发「已读/读完」与「标记未读」保留未读及归零。观察过未读后的真实读完重新标已读。仅点「标记已读」不改变已有页位。
- 删除历史只移除历史及续读选章。保留各章数据、书签、已读和接收设备已有的本机统计。发起设备保持现有行为，另清该书的本机统计。确认文案说明两端影响。收藏造成临时历史行去重不当作用户删除。清空历史为本机实际可见的历史逐键记录删除及已见版本，保留从未看到的另一端独立记录。清空搜索覆盖范围由下一条定义。同步中的删除及重置对发起时尚未观察它的本机活跃 Reader 会话形成屏障，照常阅读，迟到和退场保存不能把远端刚删除的历史或重置前页位写回；用户在下一次显式打开或从冲突中确认后才生成观察到屏障的新位置。被挡的位置保留为本机可恢复候选，本次结果说明。
- 搜索历史保留独立同步记录和删除信息，本机 owner 仍只投影最近 20 条，保留目标端原有限定查询。现有「全部」同时查私库、本地和书源，「书源」也可能包含账户源。首版仅分享实际搜索计划能证明每个目标均为受支持公开书源、无私有会话的普通查询。旧查询没有这份证据，只保留本机。收到记录按同一公开范围的可用源交集重放，无可用目标时只填词并提示，不回落到「全部」。混合范围、限定库和高级语法留本机。保留本机限定词的持久副本，不因同步投影而永久挤出。稳定键是协议固定版本的 NFC、折叠空格、Unicode 默认大小写折叠及范围枚举，禁止用系统语言参与计算。容量挤出不会产生删除，清除时包含用户当前看到的可同步条目及此前同一设备已知的隐藏旧条目，不能复活旧记录。搜索确认文案明确会清除该设备已知的搜索记录，包括列表之外的旧记录。单条删除只针对选中的键并写删除屏障，清空是只覆盖已见版本的另一种动作。其他来源限定的本机词条沿当前交互处理。搜索词是自由文本，开启前明确提示原文会到服务端，预览列出已有词；明显含访问链接或凭据格式的条目排除。
- 阅读偏好首版全局固定为 `{pageMode, readingDirection}` 组合、`pageTurnAnimation`、`showPageNumber`、`imageFitMode`。模式与方向经现有 owner 的正规化规则作为一个值。按书仅覆盖 `{pageMode, readingDirection}`。同步 set 即使和目标的全局值相同也必须保留，只有显式 clear 才删除覆盖并回到本机全局配置；须经现有 owner 新增区分 set/clear 的增量路径，避免普通写法按值相等删覆盖。不从整份 Preferences 或旧全量按书快照提取字段，恢复缺字段不产生重置。
- 书源订阅共享经过验证的发行身份、规范地址及显示名称，不同步按最近使用排的本机顺序。目标端收到的是共享候选，主动接受才经 SourceIndexService 验证和登记。保留本机活动目录、现有代理/镜像、停用及最近使用记录，已到 12 个目录的上限则继续保留候选，不挤掉任何本机订阅。同步添加、改名和撤回共享更新候选本身，不自动发网络请求、安装或改已加入本机的订阅。被接受的本机订阅在远端撤回共享后仍保留。发行者换地址作为同一已审身份的变更，目标先验证并由用户接受；同地址无受信映射不能自动并到已有目录。
- 备份创建走原本机快照。开始正式恢复前暂停同步，等待在途本地应用到安全提交点。远端最终请求等待有界超时，结果未知则封存该连接的意图、提示可能已提交，仍可继续本机恢复；恢复期间全部入口拒绝新同步。副本 ID、单调序号、连接选择、接收游标、待传操作、未决意图和上次状态均是本机同步元数据，不进备份，不随恢复回卷。恢复成功进入「待重新核对」，新旧本机记录及原待传操作隔离为候选，按仍存在的显式值和已知删除重新预览，不自动发旧队列或使用旧文件缺组/缺键/缺记录产生删除。完整回滚后恢复原调度状态，恢复无法完成时保持暂停和本机证据。

## 协议与失败恢复

- 从首版采用独立命名空间、版本化清单和每数据集分片。规范 UTF-8 键按固定算法分 64 个一级桶，作品相关记录优先同桶。超预算按完整记录键的稳定二级前缀递归细分，每个叶子独立寻址，首版预算每叶 1 MiB、清单 1 MiB、每轮下载并验证的已选状态 64 MiB，上限在真机大库样本跑完前须复核。单条超限阻止该组提交，显示范围和更新/退出该组的动作。清单含空间 ID、单调修订、写入世代、最低写入协议版本、格式和分片策略版本、各组叶子字节数及 SHA-256。清单修订每次 CAS 加一，写入世代只在进入维护时递增。相同状态产生相同排序和编码。只读写变化叶子，保留未选择和兼容的未知组。已选内容损坏或主格式不支持时停止本轮应用和上传，避免以半份结果替换本机。已识别组出现不支持的组版本、字段/动作或分片规则时，该组以不透明引用保留，既不覆盖也不应用。其他组可在用户关闭该组后继续。对象路径只能由客户端从固定前缀、世代和规范摘要构造，不能接受清单中任意 URL 或路径。
- 先上传不可变分片，再条件提交清单。第一次用 `If-None-Match: *`，已有用经无缓存 GET 取得的强 ETag 作 `If-Match`。服务器必须通过实际拒绝重复创建/过期更新并保持原内容的探针，不能把弱 ETag 或缺 ETag 当普通写入。分片写入是条件创建，相同摘要对象存在时先核验字节。清单 409/412 最多三轮拉取合并；人工预览若影响变更，停止等待新的确认。PUT 成功丢响应时重新验证空间、代次和数据事实，从同空间、同数据组、同事实的已验证远端候选或其因果向量证明某条本机操作已被接受或覆盖；不能仅以对象名是否仍引用判断。没有证明不清本机待传记录。
- 写操作边界为连接版本和空间。一次同步先从远端读取、验证、计算不可变合并计划，落盘待办意图，再发出最终条件写入；没有远端变化时用同版本条件读取验证。写请求结果不明留在可恢复意图中，重启先核对代次和操作版本，过程不生成新编辑。网络期间不锁本机 owner。应用本地前在 owner 写入队列上复核版本，新本机操作保留待传；它改变已确认的影响时，相关本机应用暂停并重新预览，显示远端是否已经提交，不宣称远端可撤回。写入暂存的操作必须来自确认过的计划或已启用自动范围。
- 本地应用同一批的数据和接收游标写入单一可重放的恢复日志，含各 owner 已验证的目标差异、目标修订及源操作 ID。在本地阶段按固定顺序取得所有参与 owner 的写入锁和发布栅栏，普通写入等批次结束，界面读取上次已发布快照。日志先持久化，随后 owner 逐个原子提交，完成标记和游标都持久化后才放行读写、向界面发布及清除确认过的待传项。失败和回滚期间仍保持该栅栏，普通用户编辑不会被回滚覆盖。提交途中退出，启动先沿日志按同一版本重做，再开放普通写入和发布。若无法重做，按日志恢复先前快照并保留待办，恢复仍失败时保持同步暂停并报告具体 owner；远端已完成、本机待恢复是显式结果。普通编辑同样须把成功落盘的变更与待传事实绑在一起；重启能恢复，不在普通 reader 热路径发网络请求。远端写入不触发源执行、第三方追踪、下载或二次上传。
- 对象名带当前写入世代及摘要。当未引用对象超过可回收预算且前台网络允许时，回收由清单条件提交进入维护世代，持久化进入前最后两份成功数据清单的精确保护集合。维护标记存在时禁止普通发布，唯一允许的清单变更是基于当前强 ETag 完成本次维护。任何支持此 writer 版本的已授权副本都可按同一固定保护集合接手；无法解析旧引用时不开始。初版客户端必须认识此状态，写入能力不满足最小协议版本的客户端只读。旧计划在旧 ETag 失败后重建，不可拿新 ETag 发布先前世代的未引用对象。新写仅创建当前世代对象或复用清单仍引用的对象；禁止从旧世代捡回已失联对象。仅删除应用自有且命名可校验、老于维护世代又不在当前或保留恢复点中的对象。旧读者遇对象缺失重新读取新清单，维护中断可按同一保护集合继续，清除维护状态也用条件提交。未知数据组无法完整解析引用时跳过回收。无过期引用可回收时不进入维护。首版长期保留因果删除信息，关闭、断开和删除历史不保证立即抹掉服务器旧对象，恢复点和旧副本需要先有兼容的淘汰策略。
- 调度共用串行任务。启动、回前台、网络恢复和落盘写入触发批量同步。前台退避到期有未送改动可自重试，退出等下次合法触发，无后台常驻。活跃阅读收到远端较新位置不自动跳页，应用下次正常打开时生效。重复拉取相同快照不重建书架、偏好或设置界面。
- 正式连接只接受 HTTPS，不允许跳过 TLS 证书检查。自动 HTTP 重定向关闭，遇到重定向让用户更新到可验证的规范目录。后续请求限定于经确认的 origin 和根路径，避免同源其他目录收到凭据。账户和口令仅本机安全存储，日志、同步、备份和探针无凭据。首次启用说明 HTTPS 保护传输，服务管理员仍能看到已选数据及清单保留对象。用户撤除某组/断开停止收发，远端记录的删除与恢复点留存独立说明。公开目录必须是已信任发行者的规范地址，无登录参数、路径凭据或不可信跳转；自定义私人地址不共享。测试用局域网临时 HTTPS 服务和受信测试证书，正式策略不因测试放宽。
- Huawei Cloud 和自建服务后续评估。复用数据范围、身份、合并和用户状态；WebDAV 对象和 HTTP 前置条件不泄漏给各数据所有者。华为云若按表同步，必须另外验证平台实际事务、删除语义和本机数据适配。

## 独立评审和验收

1. 设计先由独立上下文的代理核参考、数据和方案，逐条处理阻塞意见。设置层级、文案和上述有可见影响的差异提交用户确认后，才开始实现。
2. 开发者自测语义和真机路径。用项目门禁继续验证备份往返与旧文件兼容，新增同步行为验证覆盖并发不同字段、真实删除和恢复、首次双端有数据、时钟异常、协议中断、幂等、冲突重试、设置和安全边界。不会用匹配源码的断言替代行为。
3. 实现后由未参与编码的独立代理审完整 diff 和设计对应关系。另由独立代理用同一确切签名包和临时 WebDAV 在 197 和 103 顺序操作。按普通入口实走单栏/平板分栏、设置搜索、初次双端合并、五组选项、跨端真实续读、逐章已读/未读/书签、删除后旧离线设备回归、缺源到安装后续读、错误和恢复、退出重进及普通备份。协议故障采用独立夹具和可控 WebDAV，真实断点包括上传分片后、提交清单后、首个 owner 写入后及本机清队列前。还须演练预览后另一端删除、提交丢响应后第三逻辑副本改同桶、同空间回滚、禁用/换连接期间迟到回调、单作分片超限及回收与在途请求竞争。保留请求、条件响应、操作版本和前后持久数据核对。用隐私哨兵检查全部远端对象、诊断和备份，验证未触发下载、追踪或源执行。租约结束前恢复临时设置和测试资料，保留证据。
4. 独立评审发现的阻塞先修，再对最终提交及包复核。设计、构建、开发自测、独立验收和发布分别记事实。

### 独立验收用例

先用合成 A/B 数据和可选的第三逻辑副本重跑确定性场景，再由不同代理在 197、103 上走实际用户路径。逻辑副本不需要第三台真机。两层都固定候选提交、数据、服务证书和故障参数，分别记录实际结果。

| 初始条件和动作 | 必须观察到的结果 |
