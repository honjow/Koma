# Koma WASM 源运行职责

本文件描述当前运行边界。当前源缺陷、已采用需求与验收状态见 [CURRENT_STATUS.md](CURRENT_STATUS.md)，包与操作合同见 [source-runtime-abi.md](source-runtime-abi.md)。本文不派发开发阶段或维护演进记录。

## 当前链路

用户配置的索引或本地包 → 导入/校验 → Registry → SourceRuntimeService 准入 → TaskPool Worker → Native WAMR → DTO → 浏览/详情/阅读宿主。

| 所有者 | 当前职责 |
| --- | --- |
| SourceIndexService / SourceIndexMetadata | 索引获取、合并、缓存、订阅身份及更新候选 |
| SourcePackageImporter / SourcePackageMetadata | 包结构、元数据、图标与 WASM 校验；复用无 UI 的元数据规则 |
| SourceRuntimeRegistry / SourceRuntimeAppRegistry | 已安装身份、启用状态及持久化 |
| SourceRuntimeService | 当前源身份/能力/请求/设置/网页会话的准入及结果校验 |
| SourceRuntimeWorker / NativeSourceRuntime | 复制的 WASM 字节和受限请求上下文进入后台原生执行 |
| SourceRuntimeHttpTransport / 原生 HTTP、HTML host | 受控网络与解析；源不直接拥有宿主文件、凭据或 UI |
| BrowseViewModel / SourceRouteChromeState | 当前源内容描述、合法能力与导航入口的展示投影 |
| SourcePackageManagerCache | 页面外可用快照及后台检查后的发布 |
| SourceSettingsStore / SourceWebSessionStore | 配置和精确身份/origin 下的会话，不由展示对象授权 |
| SourceSettingObservationStore / SourceSettingObservationFile | 本源公开设置候选的进程快照、串行后台提交及卸载/备份生命周期；不改用户选择或内容缓存身份 |
| SourceChapterListResolver / SourceChapterVisibility / SourceMangaDetailSnapshotCache | 当前完整目录及源明确排除的显示投影；保留库章节/下载/进度，按安装及设置身份缓存 |
| SourceMangaMigration / SourceMangaMigrationService | 跨源作品匹配、已读对应与目标先提交；复用原书库、阅读记录和追踪持久化所有者 |

## 订阅身份

- 安装索引保留数组及既有包/图标相对地址；同目录可选 `repo.json` 的 `meta.name`、`meta.website` 提供订阅名称及 HTTP(S) 项目页，对象式索引也可内含同结构 `meta`。这不改变源包归属、网络权限或会话范围。
- 订阅名称可选，显示顺序为用户自定义名、发布者名称、订阅地址；项目页不存在时不展示无效动作。元数据与自定义名随既有订阅偏好持久保存，后台检查不覆盖用户名称。
- 名称编辑不请求索引；地址修改先验证新索引，再原子替换订阅及活动地址，失败保留原订阅。名称补全在订阅页后台进行，可下拉同步，失败保留已有信息，不阻止旧版索引使用。
- 订阅地址可独立停用，保留名称和配置。停用地址退出目录、刷新、安装及更新候选，已安装书源和书库仍由原所有者管理。HTTPS地址内嵌完整上游索引路径时可按该路径展示分组，不按代理域名列名单。分组键只用于归类。下载只使用用户已添加且启用的地址。跨地址更新或切换下载要求原订阅已有同版本、同SHA-256的发布记录。缺少可核对的摘要或摘要冲突时保留旧包。旧索引缺少摘要时仍可按原方式安装。

## 内容与准备

- Browse 的当前内容描述携带 home/listing/query/filter/page 语义；刷新、重试、分页和设置返回均重放对应描述，不能意外切回另一个列表或旧查询。
- 源浏览切换分类时立即提交目标选项。路由内存最多保留 12 份成功的首页或分类首屏，按当前安装、设置、会话和实际筛选隔离；命中时先显示该分类，再后台重取首屏。未命中先显示目标标题和加载态。失败只属于目标分类，明确需要登录时清除旧快照并复用原登录入口，成功后重试原分类。过期请求不能覆盖当前分类，分页继续沿用当前分类的游标。
- 源浏览的原生 Grid 保留现有作品键、栏目和页尾。预布局的卡片先保留封面占位，封面第一次进入可见区域才启动加载，避免屏幕外的预布局抢占源的请求额度。封面继续走原缓存、去重与限速。
- 无明确用户可处理原因的运行、初始化、解析等失败，界面只报告本次操作失败。确定的超时、限流、验证和地区限制沿用具体提示和现有恢复入口；详细分类保留在诊断日志。
- 内容未找到只说明站点没有提供本次请求的内容，并提示可能下架或链接失效；不能仅凭空目录、解析失败、网络异常或网页验证就断言作品已下架。保留已有目录和本地可读内容，不因这种提示清除数据。
- `no_chapters` 只用于源已核对网页的明确无章节状态，显示“站点暂未提供可阅读章节”；宿主不按空数组、缺失节点或错误消息猜测这种状态，网络及访问拒绝仍优先保留。未知该码的旧宿主继续沿原通用失败处理。
- `error.code: "content_removed"` 只用于站点明确标记内容下架的响应，可以同时保留 `reasonCode: "not_found"` 供旧宿主回退。普通 404、空内容或错误消息中的字样不能作为明确下架的依据。认证、访问拒绝和限速仍沿原分类。
- 单章访问限制与整部作品可用性分开。源明确的 `paid_chapter`、`chapter_locked`、`auth_required` 分别提示原站付费／会员、锁定待解锁、需要登录；`chapter_unavailable` 只说明站点没有提供本章可直接读取的图片。不能用缺失字段、通用 `permission_denied`、HTTP403 或任意错误文案推断付费，也不能因为某些章节受限阻断已开放的免费章节。HTTP拒绝仍保留实际分类，原有网页验证与会话准入不因提示文案改变。
- 源浏览页内的搜索与普通列表共用筛选面板，但筛选值、忙碌状态、修改及重置均随当前可见内容选择 search 或 browse 所有者；搜索中不能更新隐藏的列表。浏览和搜索各自的已有筛选持久化保持独立，重跑搜索须消费输入框的当前查询并取消其待执行延时。
- 行展示复用值相等的 DTO 与已解码图标身份；源运行准入仍读取实时 Registry。可用快照先显示，后台完成后差量发布，不因检查清空整表。
- App 本地元数据提交保持有序和一致；后台工作减少 UI 线程负担，不削弱提交、回滚或身份校验。
- 导入副本的完整归档读写和 WASM 读取使用异步文件接口，归档及 WASM 的完整摘要交给纯 Crypto 的 SourcePackageHashWorker；安装器保留原字节并等待校验后才注册。Importer 唯一写入解包前的归档，Registry 不重复写入；备份恢复及 rawfile 的同步辅助函数保持原合同。
- 目录方向由已核源合同声明；首次阅读按对应方向选择最早未读，已保存进度和显式章节优先。共享章序所有者为 ReaderChapterSequence，不能通过猜话数、重排或改章节 ID 适配宿主。
- 跨源迁移按源给出的唯一章号及卷号或唯一完整标题对应，不按任一目录的展示下标对应，也不填平明确未读的空洞。歧义章节留在原阅读记录；不同版本的页边界不同，续读只定位对应章，不搬旧页 ID、页码、图片 URI 或双页配对。目标已有进度、分类与追踪选择保留。
- 复制与迁移均先持久化目标书、所选已读及分类、已确认的本地追踪绑定；全部成功后，迁移才将旧书移出书库。旧历史、下载和源会话不删除、不转移，不调用远程追踪写入；失败保留旧书，重试合并已形成的目标记录。入口与允许差异以工作单 `LIBRARY_CROSS_SOURCE_MIGRATION` 的已采用决定为准。

## 并发与能力

- Worker 模块边界不得引入 UI decorator、语言状态、Registry 变更或网页会话查找；这些由调用侧完成。保留复制字节、受限 HTTP 上下文及源变更校验。
- source_info、实际导出、源设置 schema 和实际消费共同决定可用能力；不能只见 capability 标志就摆放空入口。
- 普通网页仅使用已知合法站点地址，不授予验证会话或扩大网络权限。验证流程按精确源身份、请求和 origin 认领；其它源并行结果不因验证丢弃。
- 敏感设置沿专用保护边界，不能因源有导出而开放普通明文持久。账户、网络、原图缓存和进度仍由各原宿主服务负责。

## 修改时查阅

### 站点规则与宿主能力

| 决策 | 责任 |
| --- | --- |
| 域名、镜像、查询、分页、目录顺序、图片票据、站点错误、源设置 | 源读取上游并输出明确的内容或业务声明，已有字段以内由源包独立更新 |
| 请求派发、并发队列、取消、预载、缓存、重试、响应回传 | 宿主提供有界的通用执行能力。同一来源的 API、封面及正文需要共用的规则由源声明，宿主统一执行 |
| 用户授权、凭据存储、TLS、Cookie 作用域、系统解码、阅读位置和原生界面 | 宿主实施边界。源声明所需能力或数据，站点声明不能自行扩大权限 |
| 原图 GET 的站点业务错误 | 取票阶段由源直接返回结构化错误。下载阶段由源声明状态映射，宿主按 [图片响应错误 ABI](source-runtime-abi.md#宿主特性) 显示，普通失败保留原有恢复 |

生产宿主统一读取源包的 [`requestLimits` 和 `websitePolicy`](source-runtime-abi.md#站点规则声明)。限速、浏览器兼容、镜像、游客请求、DNS初始化、旧章节身份及封面行为由安装包提供。源图标按包内素材显示，留白和主体尺寸由源仓素材规范决定。历史章节兼容继续保护已有进度和下载，声明只适用于其所属作品和源。

正文解扰和文字页模板仍是源显式选择的宿主算法。页参数和内容随源更新，新增原生解码或排版时先核对现有协议能否表达。本次站点策略迁移直接发布正式源更新。App可以直接从历史版本升级，保留原包及用户数据。旧包明确报告缺少宿主能力时沿用现有错误入口提示检查书源更新。

改动上述公共 owner 时核全部调用方和异步回写，遵守 [执行规则](agent-guides/koma-rules.md) 的关联影响与具名路径验收要求。代码合同及当前工作单是实际能力依据，参考应用不授予复制代码/资源或新增产品范围。
